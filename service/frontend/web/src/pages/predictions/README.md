# Страница прогнозирования аварийных ситуаций

## Архитектура FSD

Страница прогнозирования разбита по архитектуре Feature-Sliced Design:

```
src/pages/predictions/
├── ui/
│   ├── PredictionsPage.tsx          # Основной компонент страницы
│   └── PredictionsPage.module.scss  # Стили страницы
├── widgets/
│   ├── current-data-section/        # Виджет текущих данных
│   │   ├── CurrentDataSection.tsx
│   │   └── CurrentDataSection.module.scss
│   ├── data-table/                  # Таблица с текущими показателями
│   │   ├── DataTable.tsx
│   │   └── DataTable.module.scss
│   ├── charts-grid/                 # Сетка графиков с группировкой
│   │   ├── ChartsGrid.tsx
│   │   └── ChartsGrid.module.scss
│   ├── forecast-section/            # Виджет прогнозов
│   │   ├── ForecastSection.tsx
│   │   └── ForecastSection.module.scss
│   ├── forecast-charts/              # Графики прогнозов
│   │   ├── ForecastCharts.tsx
│   │   └── ForecastCharts.module.scss
│   ├── analytics-panel/             # Панель аналитики
│   │   ├── AnalyticsPanel.tsx
│   │   └── AnalyticsPanel.module.scss
│   └── alerts-panel/                # Панель предупреждений
│       ├── AlertsPanel.tsx
│       └── AlertsPanel.module.scss
└── index.ts                         # Экспорт компонентов
```

## Основные функции

### 🚨 Система предупреждений

- **Критические риски**: Температура ГВС, превышение нормативов
- **Предупреждения**: Потери воды, неэффективность системы
- **Информационные уведомления**: Рост потребления, изменения режимов

### 📊 Группировка данных

- **По дням**: Детальный анализ ежедневных показателей
- **По неделям**: Агрегированный анализ недельных трендов
- Автоматическое переключение между режимами

### 🔮 Прогнозирование

- Интеллектуальный анализ исторических данных
- Предсказание аварийных ситуаций
- Рекомендации по предотвращению проблем

### 📈 Аналитика

- Коэффициент эффективности системы
- Тепловой режим ГВС
- Пиковое водопотребление
- Точность прогнозирования

## Нормативы и стандарты

- **СанПиН 2.1.4.2496-09**: Температура ГВС (60-75°C)
- **СП 30.13330.2016**: Потери воды (до 15%)
- **МВК стандарты**: Эффективность системы (85-92%)

## Технические особенности

- Модульная архитектура с четким разделением ответственности
- Адаптивный дизайн для всех устройств
- Оптимизированная производительность графиков
- Интеграция с системой мониторинга в реальном времени
